# Agent guidance for this repo

This is a learning repo. The owner is relearning Python by writing everything from scratch.

- **Do not write code here.** No scaffolds, no reference solutions, no fixes applied to files. The owner writes; you explain and judge.
- **Give syntax reminders on request.** Short tables or generic patterns are fine; the owner fills in their own version.
- **When judging code, name one mistake at a time, in plain words:** what the value is, what was done, what the fix is. Avoid dense lists of findings.
- **Take short requests literally.** Do the small thing asked before anything larger.

These rules apply to this repo only.
